01Why a rewrite

v0 worked — and taught us exactly where its model ran out.

v0's ceiling

The Event was a map[string]any: every field boxed, every read a hash, field order random per run. Config was clamped per-request — a bad rate silently meant "log nothing". The sampler could drop error events. And allocation scaled with field count: 9–14 allocs, 1.6–4.8 KB per request.

v2's answer

A per-request write-ahead log: append-only typed fields on the request goroutine, sealed at End, committed exactly once into a pooled Record. Config compiles once into an immutable Runtime. The encoder emits a deterministic canonical line — 2 allocations at any field count. Errors and panics structurally bypass sampling.

The lifecycle, in one line each

Start
attach WAL to ctx · pooled event
→
Add / Set*
append typed fields, anywhere ctx flows
→
End(&err)
seal · scan · sample · commit · recycle
→
Sink
Record view or canonical bytes

One event, always: header fields, handler fields in attach order, completion fields — deterministic by construction. End is one-shot (CAS), captures panics, re-panics them, and releases the buffer even if the sink panics. Production code spawns zero goroutines — goleak-proven.

06Using it — the ten-line tour

Zero-config HTTP logging, background jobs, sampling rules, and every logger you already run — the whole API fits on one screen.

HTTP service, zero logger dependencies

import ( hc "github.com/happytoolin/happycontext"; stdhc ".../integration/std" )

sink := hc.NewJSONSink(os.Stdout)                      // first-party: canonical line, no host logger
rt := hc.MustCompile(hc.Config{Sink: sink, SamplingRate: 0.05}) // compile once; errors always kept
mux := http.NewServeMux()
mux.HandleFunc("GET /orders/{id}", func(w http.ResponseWriter, r *http.Request) {
    hc.Add(r.Context(), "user_id", "u_8472", "feature", "checkout") // variadic pairs
    hc.Add(r.Context(), "cart", json.RawMessage(preEncodedCart))     // pre-encoded JSON, verbatim
    if err := charge(r.Context()); err != nil {
        hc.SetMessage(r.Context(), "checkout_failed")
        hc.Error(r.Context(), err)                    // structured error field; bypasses sampling
        http.Error(w, "internal error", 500)
        return
    }
    w.WriteHeader(http.StatusOK)
})
_ = http.ListenAndServe(":8080", stdhc.Middleware(rt)(mux))

Every request emits exactly one line: {"level":"info","http.method":"GET","http.path":"/orders/o_1","user_id":"u_8472","feature":"checkout","cart":{…},"http.route":"GET /orders/{id}","op.name":"GET /orders/{id}","http.status":200,"op.domain":"http","duration_ms":12,"op.outcome":"success","time":"…","message":"request_completed"}

Background job — one operation, deferred error capture

func runImport(ctx context.Context, rt *hc.Runtime) (err error) {
    op := hc.Start(ctx, rt, hc.OperationStart{Domain: hc.DomainJob, Name: "import", ID: "job_8472", Attempt: 2})
    ctx = op.Context()                     // switch, or every Add below is a no-op
    defer op.End(&err)                    // commit exactly once; captures errors AND panics; re-panics

    hc.Add(ctx, "rows", 42, "source", "queue")
    return doImport(ctx)                     // non-nil err → error field + outcome=failure + ERROR level, kept
}

Sampling rules — compose what you keep

rt := hc.MustCompile(hc.Config{
    Sink: sink,
    Sampler: hc.ChainSampler(
        hc.RateSampler(0.05),                       // base: 5% of healthy traffic
        hc.KeepErrors(),                            // belt-and-suspenders (bypass is structural anyway)
        hc.KeepPathPrefix("/admin"),                  // always keep admin
        hc.KeepSlowerThan(250*time.Millisecond),           // always keep slow
        func(next hc.Sampler) hc.Sampler {           // custom: read the request's fields
            return func(in hc.SampleInput) bool {
                if tier, _ := in.Lookup("user_tier"); tier == "enterprise" { return true }
                return next(in)
            }
        },
    ),
})

Your logger, your pipeline — bridges stay out of the way

slogSink  := sloghc.New(slog.Default())              // log/slog — native attrs
zapSink   := zaphc.New(zapLogger)                  // zap — typed fields
zeroSink  := zerologhc.New(&zerologLogger)          // zerolog — 7ns fast path on plain loggers

hc.Add(ctx, "took", 1500*time.Millisecond, "ok", true) // typed: duration, bool — no boxing
hc.SetLevel(ctx, hc.LevelWarn)                   // severity floor (raises, never lowers)
hc.SetRoute(ctx, "GET /orders/{id}")               // middlewares do this for you

Same Record reaches every bridge; cross-bridge parity tests guarantee they agree on the canonical field set. A custom sink is one method: Write(ctx, rec *hc.Record) — read Fields()/Lookup during the call, or take rec.Encoded() bytes (copy to retain).

07Hard-won guarantees

v1.0.0 ships after six independent model audits and two adversarial crash-testing rounds — 16 defects found and fixed along the way, zero known open.

  • Failures are never sampled away — structural bypass before any custom sampler
  • One event per request, even under abuse — concurrent End, double-End, End-from-closure, nested operations: all characterized and pinned
  • Stragglers are no-ops — async writes after End can't corrupt the pool (generation-guarded recycle; the nanosecond TOCTOU residual is documented)
  • Panics can't take the pipeline down — sink, sampler, and marshaler panics contained; typed-nil and %w-wrapped typed-nil errors render <nil>
  • The wire never lies — flush-then-panic logs the status the client received; canonical-code semantics are coherent per domain (non-HTTP 5xx op.code resolves failure)
  • Zero goroutines in production — goleak-gated suite, synctest bubbles for per-test hygiene
  • Deterministic output — insertion order, LWW dedupe, envelope aliasing: golden and cross-bridge parity tests hold the canonical line to every bridge
  • v1.1, already paved: the armed-mode watchdog protocol ships in the core (no callers yet, no breaking change later); buffered sink + in-flight records follow the plan
