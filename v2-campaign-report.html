01The Goal

What v2 set out to do, as locked in V2_DESIGN.md before a line was written.

Thesis

One structured, canonical event per request. Stop scattering fragmented log lines; make debugging start from a complete record. A request-scoped write-ahead log (WAL), append-only, last-write-wins, committed exactly once at End.

The four pillars

① Compiled, immutable Runtime — bad config is a construction error, never a per-request clamp. ② Zero shared mutable state on the request path; production spawns zero goroutines. ③ Structural error/panic sampling bypass — failures can never be sampled away. ④ Small, straight API: everything v0 taught us to remove, removed.

Release contract: performance gates with benchstat evidence vs the v0.4.0 baseline; full 3-version Go matrix (1.25/1.26/1.27) green under -race; a published MIGRATION.md before merge; 1.0.0 cut via lockstep release-please on the v2 line.

The frozen surface after the campaign, including the final decision: the raw-JSON path died because json.RawMessage through Add already does the job with bridge parity.
